# ARASAAC Local Datasets

Generated by: `python datasets/update_datasets.py`

## Layout

```
datasets/
  {lang}/
    _meta.json            Per-file build timestamps and record counts.
    keywords.json         Full keyword list for that language (list of strings).
    pictograms.json       { id_str → PictogramRecord } — all pictograms.
    keyword_index.json    { keyword → [id, ...] } — enables offline search_pictograms().
    synset_index.json     { synset_id → [id, ...] } — enables offline search_pictograms_by_synset().

  pictograms/
    {id}.png              Language-independent images (downloaded on demand or via --download-images).
```

## _meta.json

Each language directory contains a `_meta.json` that records when each file was
last written and how many records it contains:

```json
{
  "pictograms":    { "built_at": "2025-04-17T15:00:00Z", "count": 13780, "added": 0, "updated": 3 },
  "keywords":      { "built_at": "2025-04-17T15:00:00Z", "count": 18400 },
  "keyword_index": { "built_at": "2025-04-17T15:00:00Z", "count": 18400 },
  "synset_index":  { "built_at": "2025-04-17T15:00:00Z", "count": 3211 }
}
```

`built_at` is the UTC timestamp of the run that wrote each file. For
`keyword_index` and `synset_index` (derived from pictogram records, with no
upstream timestamp of their own) `built_at` reflects the run that rebuilt them,
which occurs on every run — so you always know how fresh the derived files are.

## PictogramRecord fields

| Field | Type | Notes |
|-------|------|-------|
| `id` | int | Unique ARASAAC pictogram ID |
| `keyword` | str | Primary label (keywords[0]) |
| `synonyms` | list[str] | All other keyword strings for this pictogram |
| `categories` | list[str] | Thematic categories (e.g. "food & drink") |
| `synsets` | list[str] | WordNet synset IDs (e.g. "00854425-v") |
| `tags` | list[str] | Free-form editorial labels |
| `sex` | bool | Content safety flag |
| `violence` | bool | Content safety flag |
| `schematic` | bool | Simplified/schematic variant |
| `aac` | bool | Suitable for AAC use |
| `aacColor` | bool | Colour AAC variant available |
| `skin` | bool | Has skin-tone variants |
| `hair` | bool | Has hair-colour variants |
| `created` | str\|null | ISO 8601 creation timestamp |
| `lastUpdated` | str\|null | ISO 8601 update timestamp — used for incremental updates |

## How the dataset is built

A single `GET /pictograms/all/{lang}` request returns all ~13 800 pictograms for
a language. This replaces the old per-keyword search approach (~7 000 requests,
~20 minutes per language). The full build now takes a few seconds.

The keyword list (`keywords.json`) is derived directly from the merged pictogram
records (primary keyword + all synonyms) rather than from a separate
`/keywords/{lang}` call, so it stays in sync automatically.

`keyword_index` and `synset_index` are rebuilt from the pictogram records on
every run, covering the primary keyword and all synonyms of every pictogram.

## Incremental updates

On re-runs, a pictogram is only updated if ARASAAC's `lastUpdated` timestamp is
newer than the one stored locally. Unchanged records are skipped entirely. Use
`--force` to re-fetch everything regardless.

## Synsets vs Tags vs Categories

**Synsets** — WordNet synset IDs like `"00854425-v"`. Language-independent concept
identifiers. The most semantically precise handle for retrieval.

**Tags** — Free-form editorial labels added by ARASAAC editors. Language-dependent.

**Categories** — Broad thematic groupings. Language-dependent. Good for browsing.

## Images

Images are **language-independent** — the same PNG serves all languages.
Stored in `datasets/pictograms/{id}.png`. The MCP server downloads them lazily
on first use via `_DatasetCache.get_pictogram_image()`. Pre-download with
`--download-images`.

## Commands

```bash
# Full build for all languages in config.DATASET_LANGS:
python datasets/update_datasets.py

# Specific languages:
python datasets/update_datasets.py --langs en it

# Force full re-fetch (ignore lastUpdated):
python datasets/update_datasets.py --force

# Also pre-download all pictogram images:
python datasets/update_datasets.py --download-images

# Verbose logging:
python datasets/update_datasets.py --verbose
```

## Notes

- Dataset files are **not committed to git** (see .gitignore).
- A full first build for one language takes a few seconds (1 HTTP request).
- Subsequent incremental runs are equally fast — only changed records are written.
